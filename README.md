# Лагуна — локальная читалка таблиц

Лёгкий локальный сайт, в который можно перенести данные из Google Sheets
(или любых CSV/TSV/JSON) и читать их с удовольствием: поиск, сортировки,
фильтры по значениям, статистика по столбцам, карточка строки, экспорт.

Серверная основа — **nginx в Docker Compose**: статика + один JSON-файл с данными, без баз и API.

## Запуск

```bash
docker compose up -d --build
```

Откройте **http://localhost:8090** — готово.

Остановить: `docker compose down`. Пересобрать после изменений: `docker compose up -d --build`.

## Как перенести данные из Google Sheets

Есть три способа — можно комбинировать:

1. **Вставка из буфера (самый быстрый).**
   В Google Sheets выделите диапазон (`Ctrl+A`), скопируйте (`Ctrl+C`),
   на сайте нажмите «Перенести данные» и вставьте (`Ctrl+V`).
   Разделитель (табуляция / `;` / `,`) и заголовки определятся автоматически.

2. **Файлом.** В Google Sheets: *Файл → Скачать → CSV*, затем загрузите файл
   на сайте (поддерживаются `.csv`, `.tsv`, `.txt`, `.json`; JSON может содержать несколько листов).

3. **Серверным файлом `data/data.json` (для docker-версии).**
   Положите JSON в папку `./data` рядом с `docker-compose.yml` и обновите страницу —
   при пустом хранилище сайта данные подхватятся автоматически.
   Пример формата — в [`data/data.json.example`](data/data.json.example):

```json
{
  "title": "Мои данные",
  "sheets": [
    { "name": "Лист 1", "columns": ["A", "B"], "rows": [["1", "текст"], ["2", "ещё"]] }
  ]
}
```

Вставленные данные хранятся **локально в браузере** (localStorage) — никуда не отправляются.
Экспорт: CSV (с учётом фильтров), JSON всего датасета, Markdown-таблица в буфер.

## Возможности

- несколько листов (вкладки), переименование двойным кликом, добавление/удаление листов;
- поиск по всем столбцам с подсветкой, сортировка по клику на заголовок;
- фильтр-«воронка» по уникальным значениям каждого столбца;
- скрытие столбцов, плотность строк («Крупно / Компактно»), пагинация;
- липкая шапка и строка итогов (Σ по числовым столбцам);
- карточка строки (клик) с листанием `←`/`→`, правка ячеек двойным кликом;
- статистика: сумма, среднее, мин/макс по числовым столбцам, уникальные значения по текстовым;
- тёмная и светлая темы в синих тонах.

## Локальная разработка (без docker)

```bash
npm install
npm run dev
```

## Структура

```
├── Dockerfile            # сборка фронтенда + nginx
├── docker-compose.yml    # порт 8090, монтирование ./data
├── deploy/nginx.conf     # gzip, SPA-fallback, no-store для /data
├── data/                 # сюда кладётся data.json
└── src/                  # React + Vite + Tailwind (интерфейс)
```
